[CONTRIBUTING](../CONTRIBUTING.md) says how to send a change.

| Guide | Read it when |
|---|---|

| [How the app is built](architecture.md) | You want to find your way around the code. |
| [Words VWB uses](vocabulary.md) | You are writing anything people will see, or reading the database. |
| [Choices made on purpose](design-decisions.md) | Before you change how a feature works. |
| [Privacy and security](privacy-and-security.md) | Always. These rules are never broken. |
| [The database](database.md) | Your change needs a new table, column, rule or function. |
| [Writing and Spanish](writing-and-spanish.md) | You add or change words on screen. |
| [Screen checklist](ui-checklist.md) | You change anything people see. |
| [Code style](formatting.md) | You write code. |
